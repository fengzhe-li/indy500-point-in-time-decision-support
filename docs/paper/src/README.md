# Paper source

LaTeX source for `physics_conditioned_probabilistic_performance_inference.pdf`.

Reconstructed from the original compiled PDF (no prior `.tex` source was tracked) and
updated for FINAL_V3: new Section 10 "Point-in-Time Historical Shadow Evaluation",
updated Abstract, Discussion, Limitations/Future Work, and Conclusion. All prior
FINAL_V2 scientific content is preserved verbatim in content; only structure/typesetting
changed during reconstruction.

Build with [tectonic](https://tectonic-typesetting.github.io/) (no local TeX install required):

```bash
tectonic main.tex
```

Figures referenced by the paper live in `figures/final_v3/` (new FINAL_V3 figures) and are
generated by the scripts in `figures/final_v3/generate/` (see repository root `figures/`
for the full original figure set).
