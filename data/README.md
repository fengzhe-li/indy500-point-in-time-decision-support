# Data

This directory is intended for the compact, documented data products required to reproduce the final frozen analysis and publication figures.

The full historical reconstruction workspace contains many intermediate evidence captures, quarantined records, chronology audits and source-specific extraction artifacts. Those files are intentionally not treated as independent statistical observations and should not be dumped into the public modelling dataset without provenance review.

## Frozen modelling unit

The principal modelling unit is a same-car transition between two complete four-lap qualifying attempts.

The frozen 2020–2024 physical-response core contains **41 evidence-qualified transitions**.

## Data policy

Files added here should be one of:

- final modelling tables;
- plotting tables used by publication figures;
- frozen validation summaries;
- compact QA tables required to understand a frozen result.

Raw downloaded source material, caches and large exploratory intermediates should remain outside the public repository unless redistribution is clearly appropriate.

## Reproducibility boundary

Historical evidence reconstruction is part of the project contribution. Consequently, a row should not be promoted into a final modelling table merely because it exists in a scraped or parsed source. Attempt identity, chronology, completeness and environmental linkage must remain defensible.
